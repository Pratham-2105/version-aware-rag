# StudyBuddy — Study Group Platform

## Status: ABANDONED (Do not reopen)

### What It Was
A MERN stack web app for college students to form study groups, share notes, and track assignments. Had real-time chat via Socket.io.

### Tech Stack
React, Node.js, Express, MongoDB, Socket.io

### What Got Built
- User auth (JWT)
- Group creation and joining
- Note sharing with file uploads
- Real-time group chat
- Assignment tracker with deadlines

### Why Abandoned
I pivoted from web dev to ML in July-August 2026. The core features work but I have zero motivation to maintain a MERN app. It served its purpose — I learned full-stack development. Moving on.
